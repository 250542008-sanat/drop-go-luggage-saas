# Drop&Go - White-Label Luggage Storage SaaS

Welcome to **Drop&Go**, a White-Label Luggage Storage SaaS platform designed to simplify luggage storage management for businesses.

Drop&Go allows businesses to manage luggage storage points, track daily volumes, monitor revenue, generate PDF receipts, and manage bookings using QR code scanning.

The platform includes customizable branding, multilingual support, role-based authentication, analytics, and Docker-based deployment.

## 🌟 Key Features

### 🎨 White-Label Ready
- Customize the application name from the Admin Panel.
- Configure the default currency.
- Change the default language.
- Adapt the platform to your business identity without modifying source code for supported settings.

### 🌍 Multi-Language Support
- English and Turkish support.
- Dynamic template rendering.
- Language configuration through the administration panel.

### 📊 Smart Dashboard
- Monitor revenue and luggage storage volumes.
- Visualize business performance using Chart.js.
- Track daily storage activity.
- Access key business statistics through the store dashboard.

### 📱 QR Code Engine
- Scan booking references.
- Identify luggage storage bookings.
- Facilitate luggage status updates.

**Supported luggage statuses:**
- `Pending` — The luggage is awaiting storage.
- `Stored` — The luggage has been checked in.
- `Retrieved` — The luggage has been collected.

### 🧾 PDF Receipts
- Generate downloadable PDF receipts.
- Simplify transaction documentation.
- Provide customers with digital receipts.

### 🔐 Authentication and Authorization
- JWT-based authentication.
- Bcrypt password hashing.
- Role-based access control.
- Separate administrator and store owner roles.

### 🐳 Docker Ready
- Docker Compose deployment.
- Simplified application setup.
- Containerized deployment environment.
